Background
In 2022 Clarkson University partnered with Carnegie (formerly mStoner) to reimagine its institutional website. Carnegie's discovery sessions identified the need to bring Clarkson's brand and story to life, prioritize user experience and accessibility, and integrate multiple systems into a single, streamlined web presence. Carnegie prepared the creative and content strategy and produced a technical blueprint for a new site built in Drupal 9. Knectar (referred to as "our team" in this case study) was engaged to implement that strategy on Pantheon.

Goals
The project's priorities were clearly defined in the technical strategy document:

  • Launch a high‑performing, accessible website that meets WCAG 2.1 AA standards.
  • Provide a sustainable and modern Drupal CMS so distributed editors can create flexible pages with ease.
  • Consolidate subdomains and migrate existing Drupal 8 content into a single Drupal 9 site.
  • Integrate with existing systems such as PeopleSoft for faculty data, EMS for events and RaveAlert for emergency notifications.

The team also needed to improve search, enable personalization using Carnegie's Clarity tool, and accommodate future enhancements.

Design and Strategy by Carnegie
Carnegie provided the creative vision and web‑governance strategy. Their discovery work captured stakeholder goals such as showcasing faculty research, making program information easier to find and creating consistent, streamlined user paths. Carnegie's design system emphasised inclusive language, representation of Clarkson's warm community, and the distinctive sense of place across its three campuses.

On the technical side, Carnegie prepared non‑proprietary front‑end code using modern tooling (PostCSS, webpack, NPM). This "from‑scratch" approach avoided bloated frameworks and produced a living style guide for Clarkson's future use. Carnegie also established a flexible Drupal architecture based on Content Types and Paragraphs, enabling editors to assemble pages from modular components such as hero banners, statistics, feature panels and testimonials. They advocated for personalization via Clarity and recommended replacing Solr with Funnelback to deliver relevant search results across Drupal and external WordPress sites.

Our Implementation on Pantheon

Infrastructure and Deployment
Our team implemented the new site on Pantheon, taking advantage of its dev/test/live workflow and automated deployment pipeline. Pantheon's container‑based architecture allowed us to implement Drupal 9 with robust caching and scalability. Git‑based version control ensured traceable updates, and we configured continuous integration to promote builds from development through staging to production. This setup reduced risk during content migration and allowed non‑technical stakeholders to preview updates before launch.

Drupal 9 Build
Using Carnegie's front‑end code and design system as a foundation, we built a custom Drupal 9 theme and a suite of content types matching the specifications document. Key templates included:

  • Homepage – featuring fixed hero and testimonial components, statistic panels and a customizable feature slider.
  • Full‑width pages for section landing pages and tertiary pages for general content, both allowing editors to insert paragraphs such as hero banners, testimonial quotes, feature panels, visual router grids and statistics.
  • Program pages and a program finder. The program finder searched by program name and keywords and grouped related degrees into expandable drawers, a design similar to Harvard's program finder.
  • Event detail pages, news/story content types and microsite templates with separate headers/footers.

Custom modules were developed to support advanced features such as Funnelback search integration, emergency alert banners and Slate/Qualtrics form embeds. We also implemented the Clarity personalization scripts and configured Google Tag Manager and CrazyEgg analytics tools as recommended.

Accessibility
Accessibility was treated as a foundational requirement. We worked closely with Carnegie's designers to ensure semantic HTML, proper heading structure and keyboard‑navigable components. Alt text fields were enforced for images, ARIA labels were added to interactive elements, and color palettes were tested for sufficient contrast. In addition, we integrated a site‑wide accessibility monitoring system (e.g., SiteImprove or DubBot) as suggested in the technical strategy. This system runs automated scans, flags issues and provides remediation guidance, complementing manual audits to ensure ongoing WCAG 2.1 AA compliance.

PeopleSoft Directory & Faculty Profiles
One of the most significant technical challenges was creating a dynamic faculty directory. Clarkson maintains its directory data in PeopleSoft and exports the information nightly into a file. Our team built a Drupal module that reads this export every morning and updates Drupal profiles accordingly. The integration populates fields such as name, title, department, email, phone, office location, mailbox and office hours. Editors can override certain fields (e.g., name or email) while fields like title and department remain authoritative.

Beyond basic contact details, faculty profiles include a Bio paragraph and additional sections like education background, experience, research interests, teaching interests, grants and publications. We implemented WYSIWYG paragraphs for these sections, giving faculty the ability to enrich their profiles. The module also records PeopleSoft overrides and headshot images, and it supports adding custom paragraphs such as accordions or tables for special content.

For public visitors, we created a faculty directory listing that queries the pool of profiles and renders them using the tertiary page template. We replicated Clarkson's interactive org chart for departments, again sourcing data from PeopleSoft. Our solution ensures that faculty data stays current while giving Clarkson control over editorial content. We continue to provide ongoing import and cleanup support, monitoring nightly imports, resolving data anomalies and coordinating with Clarkson's IT team to adjust field mappings as PeopleSoft changes.

Search, Events and Other Integrations

Search: We configured Funnelback to index both the Drupal site and external WordPress sites (e.g., announcements.clarkson.edu), delivering unified search results that are styled to match the new design.

Calendar: The specification recommended using Clarkson's EMS calendar as the master source for events. We set up RSS imports to display upcoming events on key landing pages and built an optional integration to pull EMS data directly into Drupal for a seamless experience.

Forms and Chat: The site continues to use a combination of Slate and Drupal webforms; our team styled sample forms per the design and ensured that embedded Slate forms post directly to Slate while Drupal webforms store submissions locally. We configured the Unibuddy/Slate chat widgets and emergency alert banner so editors can toggle them as needed.

Microsites: We implemented functionality for microsite sections with distinct headers, footers and navigation sets. These sub‑sites live within the main Drupal installation but can present unique branding while still leveraging the shared design system.

Migration and Training
Migrating content from the legacy Drupal 8 site required careful planning. We built migration scripts to map old content types to the new structure, preserving metadata and redirecting URLs. Two types of redirects—server‑level patterns and page‑level rules—were implemented to handle the change in URL schema. After launch, we conducted training sessions for Clarkson's distributed editors, demonstrating how to assemble pages using paragraphs, manage the directory overrides and use Funnelback search reporting to refine content.

Impact
The new clarkson.edu site launched on Pantheon with a modern, flexible architecture and fully responsive design. Key outcomes include:

  • Accessibility compliance: The site meets WCAG 2.1 AA standards and continues to be monitored through automated tools.
  • Improved search and navigation: Funnelback provides comprehensive results, and the program finder makes it easy to explore academic offerings.
  • Unified faculty directory: Nightly PeopleSoft imports ensure accurate faculty data while allowing rich, editable biographies.
  • Enhanced user experience: Modular templates and personalization capabilities create engaging pathways for prospective students and other audiences.
  • Sustainable CMS: Editors across campus can build pages without developer assistance, and Pantheon's workflow enables safe updates and continuous improvement.

Conclusion
Clarkson University's website redesign is a prime example of effective collaboration. Carnegie Higher Ed provided the strategic vision, brand positioning and design system, while our team executed the technical implementation on Pantheon, ensuring accessibility, system integrations and long‑term maintainability. By integrating PeopleSoft data, enabling personalization and building a flexible Drupal 9 foundation, we delivered a site that meets Clarkson's goals today and can evolve with the university's needs.
